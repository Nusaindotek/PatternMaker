# PatternMaker V1

Prototype offline untuk mesin pola pakaian anak.

## Menjalankan
Buka `index.html` melalui web server lokal atau gunakan GitHub Pages.

## Fitur V1
- Input ukuran anak
- Rib knit / woven
- Negative ease sederhana
- Basic bodice front/back
- SVG preview
- Download SVG

## Catatan penting
Rumus drafting di V1 adalah prototype untuk pengembangan software, bukan pola produksi yang sudah divalidasi. Sebelum dipakai untuk produksi, hasil harus diuji dengan pola kertas/kain dan dikalibrasi terhadap sistem drafting yang dipilih.
